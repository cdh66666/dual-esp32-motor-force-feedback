# 连续转动的角度同步波动

原数据：encoder-fixed-pwm-1788880021448.jsonl，固定PWM246/369、双板正反20秒。排除前5秒，36角度桶，前半时段建立曲线，后半验证；不是随机交叉拆分相邻样本。

- 滤波速度检查：angle-periodicity-1788883290078.json。
- 原始14位角度增量检查：angle-periodicity-1788883325137.json。每相邻样本展开角差、除以时间，角度归到该区间中点，消除直接使用末点角度对应延迟速度造成的相位偏差。

原始增量的角度曲线对后半记录波动解释比例95.1–98.9%。二阶谐波（每电机圈两次）占主导，相对平均速度的幅度COM4约16.6–20.0%、COM23约25.6–34.8%，不是角度误差百分比。

9%PWM时正反方向原始速度角度曲线相关系数COM4 .99865、COM23 .99703；6%时分别.98408/.97149。同方向跨两速度档也高度一致。

因此主要波动不是随机USB掉读或仅由速度滤波产生，且具有强烈转子角度相关性。此前“连续多圈无跳读”只验证读取连续性，不能排除平滑的周期角度畸变。

但同一传感器的角度与差分速度不是独立测量，不能凭此判定磁编码器损坏，也不能据此直接制作角度修正表：真实机械速度/转矩纹波也可能角度同步。需要独立速度/角度证据或电气交叉检查来区分。未更改固件角度、未滤掉用户波形、未进行新运动。
