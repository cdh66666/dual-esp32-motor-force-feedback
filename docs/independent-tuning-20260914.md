# 两板独立调教与曲线跟随 · 2026-09-14

用户先要求两台共用 COM23 参数，COM4 复测出现反向定位摆动，随后明确改为每台独立调教。本记录取代此前“COM4 未修改”的当前状态描述；早期记录作为历史保留。

## 最终配置（电机轴单位）

| 板 | USB 序列号 | 速度 Kp / Ki | 位置 Kp / Ki / Kd |
| --- | --- | --- | --- |
| COM4 | 68EE8F5381E4 | 0.001 / 0.008 | 8 / 0 / 0 |
| COM23 | 68EE8F52A79C | 0.0004 / 0.008 | 12 / 0 / 0.05 |

两台均 STOP/sleep 后执行 `cascade save_outer` 并收到成功 ACK，配置保存在各自板内的电机档案 namespace，不依赖 COM 号。COM4 本轮已烧录与 COM23 相同的持久化功能固件。两台方向/采样极性分别保留 normal/normal 和 invert/invert。
电流环、限流、力反馈逻辑未改；最大位置速度设置仍为输出轴 15 r/s，并不保证实际达到。

## 实测

- 把 COM23 参数直接复制给 COM4：3 秒保持试验第三步未通过，末段摆幅 2.15°。原始记录 `evidence/position-authority-live-1789356113971.json`。
- COM4 候选 0.0006/0.004、位置 12/0/0 短测通过，但延长到 5 秒后第三步误差 0.87°，未最终采用。记录 `position-authority-live-1789356365158.json`。
- COM4 最终独立参数：两轮四步、每步保持 5 秒通过。第一轮 `position-authority-live-1789356455928.json`。
- 两板最终逐台复测：`evidence/position-authority-live-1789356569254.json`，每板输出轴 +18°、0、−18°、0，各保持 5 秒，8 步全部通过。末 200 ms 平均绝对误差 COM4 最大 0.0962°、COM23 最大 0.0597°；末段峰峰值 COM4 最大 0.0058°、COM23 记录为 0。当前采样峰值电流分别 0.535 A / 0.476 A。
- 两轮间复测启动前 COM4 发生 USB 写超时/未 ACK，无试验数据；恢复接口重新取得 idle 状态，坐标和参数表明板已重启，重新下发最终参数并保存后复测通过。记录 `position-authority-live-1789356483171.json`。通信异常根因未在本任务内解决，不宣称 USB 长期稳定。
- 最终两台 idle、awake=0、PWM=0、nFAULT=1。角度由后轴编码器推算，100 Hz 遥测；不等于输出轴齿隙、高带宽电流纹波、大行程、加载或长期温升验收。

## 界面

默认只勾选位置；手动滑条 pointerdown/input/change 时同步切换上下两窗为对应通道，并同步纵轴缩放通道。用户仍可手动勾选叠加；下次操作滑条重新跟随。显示切换本身不发送额外运动命令。
隔离浏览器测试覆盖默认位置、三种通道切换、双板/单板选择、指令合并、停止取消排队、力反馈互斥；均通过。agent-browser 实际页面快照验证默认仅位置勾选。未在真实网页上拖动大范围滑条做硬件测试。
