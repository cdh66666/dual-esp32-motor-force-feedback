# 滑行停止与模型计算自动整定

## 驱动模式依据

率能 SS6952T 数据手册，设备功能模式，表 1（第 10 页）：
https://doc.chipmall.com/datasheet/rev_2412131225_leadpower-ss6952t-et-tp_c84036616.pdf

MODE1=1 的 ENBL/PHASE 接口中，ENBL=0、DECAY=0 输出 L/L（刹车）；ENBL=0、DECAY=1 输出 Z/Z（滑行）。0.5.8 在 STOP 撤去 ENBL 前先拉高 DECAY；下一次非零驱动恢复运行衰减配置。没有把运行 PWM 的整个衰减模式盲目改成 fast。滑行不主动抱死转轴；体二极管回灌、储能和电源保护仍须实测，不能保证一切反向电流消失。

## 自动整定真实实现范围

主按钮运行 `runAutoTune(false)`，不是旧的仅采集分支：

1. 保存现有三环、脱困辅助和保持设置。
2. 逐板 ±150/±300 mA、180 ms 有界激励，板端限时 220 ms、PWM 900；读取 2 kHz RAM 电流记录与 100 Hz 速度记录。
3. 初始低速窗口拟合 `V = R i + L_eff di/dt + Vdrop sign(i)`；L_eff 含测量滤波等动态，不声称是认证绕组电感。对运动段拟合 `dv/dt = a i - b v - c sign(v)`，v 为电机轴度每秒。
4. 留出一个脉冲组验证，归一化回归拒绝奇异/非物理/误差过大的模型。电压是 PWM×母线代理，不是端电压测量。
5. 由 R、L_eff 和母线计算电流 PI；由机械 a/b 和带宽分离计算速度 PI、位置 P。候选是模型带宽缩放，不再固定比较几组 PID。
6. 电流稳态误差、RMS 与峰值复测；正反向 ±5° 定位比较；优选后再独立复测。通过才保留本次连接中的三环参数，失败回退。不是全工作电流/全负载/全速最佳性能认证，也未永久保存控制增益。

## 验证与部署

- 新固件编译通过；合成模型、不可辨识拒绝、取消回滚、双板启停和位置指标测试通过。
- COM4（68EE8F5381E4）已烧录并校验，回读 `0.5.8-coast-autotune`，停止时 `enbl_pwm=0 decay=1 awake=0`；保留额定 24 V、电流上限 1.5 A、减速比 5.2。
- COM23（68EE8F52A79C）首次下载切换出现 Windows 设备错误 31，PnP 重启被拒绝，未绕过权限。用户物理拔插 USB 后，经 COM18 ROM 成功烧录并校验，应用 COM23 回读 `0.5.8-coast-autotune`；`enbl_pwm=0 decay=1 awake=0`、母线 0.05 V，保留 24 V / 1.5 A / 5.2。
- 最后向 COM4 再发送 STOP，确认 `decay=1 awake=0 pwm=0`。启动时 DECAY 默认低，但驱动仍睡眠；`setDriverAwake` 在唤醒前调用 `motorStop()` 设置滑行，未发现启动直接短刹路径。
- 两板升级完成。本轮没有重新供电或发运动目标；实际三环整定与停机电流峰值验收仍待恢复电机供电后执行，不能将烧录和软件测试视作实机验收。
