# 通电后自动整定实测

- 两板固件回读 0.5.8-coast-autotune；供电约 19.6–19.7 V。没有启动力反馈。
- 首轮暴露前端 trace 命令没有要求 ACK，导致 meta 未定义。已修复并新增 mock 传输回归测试。
- 第二轮 300 mA / 180 ms 触发位移边界。保持 25° / 0.8 A 限制，将 300 mA 激励缩短至 80 ms，板端期限 120 ms；150 mA 仍为 180 ms，期限 220 ms。
- 第三轮两板均收齐四个脉冲。COM4 高速记录峰值绝对电流 0.32711 A；COM23 0.34086 A。这是本次有源脉冲采样峰值，不是停机峰值、绕组 PWM 纹波或最大允许电流。
- 八个脉冲的前 40 ms 都不满足全段输出速度低于 5°/s，电气模型可用样本不足。未执行计算增益后的验证和采用，两板恢复原参数。
- 根因：当前近静止电气辨识假设不适配该电机的自由空载加速。后续须对运动期间反电势建模，并验证电流/速度时间对齐与独立数据误差，不能简单放宽近静止阈值或把默认 R/Ke 当实测值。
- 原始记录：evidence/autotune-powered-20260908.json。离线回放测试复现两板模型拒绝，无硬件动作。
- 最后 STOP + sleep 均返回成功，STATUS 确认 awake=0、pwm=0、control=idle、nFAULT=1。电机供电仍在，没有自动恢复运动。
- 反向停机尖峰与双板受力稳定性尚未验收。
