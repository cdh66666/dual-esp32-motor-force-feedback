# COM23 位置振荡调试 · 2026-09-14

## 结果与范围

用户确认两台松开、无人接触、无阻挡，授权短时小幅测试。仅 COM23 执行输出轴 +18°、回原点、−18°、回原点；COM4 停止用于保留对照参数。
电机 36GP-555，减速比 5.2，约 19.5 V 共用供电。所有角度均由后轴编码器推算，不是输出轴独立计量，不包含齿隙测量。

原参数第三次定位在到达目标后出现振荡，末段位置峰峰值约 14.52°、平均绝对误差 4.22°，记录电流峰值 1.206 A。不是单纯网页曲线噪声。
降低外环增益后同类试验通过，支持原外环增益对该装置稳定裕度不足的判断；没有单独辨识电流带宽、机械负载或逐个增益的因果贡献，不能据此断言编码器硬件完全无问题。

| 固件电机轴参数 | 原值 | COM23 采用 |
| --- | --- | --- |
| 速度 Kp | 0.0008 | 0.0004 |
| 速度 Ki | 0.016 | 0.008 |
| 位置 Kp / Ki / Kd | 12 / 0 / 0.15 | 12 / 0 / 0.05 |
| 电流 Kp / Ki | 600 / 600000 | 不变 |
| 位置最大速度 | 输出轴 15 r/s | 不变 |
| 工作电流上限 | 1.2 A | 不变 |

候选 Ki=0.004 时 1.2 秒末误差约 0.75°，未通过，未采用。
最终候选先后通过两轮 1.2 秒/步、一次 3 秒/步；板内保存并重新烧录启动后再通过一次 5 秒/步，共 16 个通过的小幅定位步骤。

重启后 5 秒/步试验：末 200 ms 平均绝对误差 0.006～0.035°，峰峰值 0～0.0058°；首次进入 ±0.5° 约 0.22～0.79 秒（不是严格稳定时间）。记录电流峰值 0.604 A。这些是约 100 Hz 遥测数据，不是高带宽电流尖峰验收。未验证满速、大行程、加载或长期温升。
