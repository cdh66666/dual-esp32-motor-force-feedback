# 电气交叉检查：周期速度波动尚未独立确认

记录 `evidence/back-emf-periodicity-1788883411166.json`。固定PWM连续运动数据，使用区间中点原始角差速度，并将V≈PWM×母线、电流与di/dt按同一角度桶比较；估计E=V-RI-Ldi/dt。另保留R=1/2/4/6Ω、L=0/.02H敏感性结果。

9% PWM、既有R/L下，每电机圈两次的归一化幅度：

| 板 | 角差速度 正/反 | 估计反电动势 正/反 |
|---|---:|---:|
| COM4 | 18.2% / 17.3% | 1.68% / 1.99% |
| COM23 | 27.2% / 24.9% | 4.03% / 3.84% |

两种估计不呈现同等幅度的周期变化。这使“角度测量存在周期畸变”成为需要优先排除的假设，但尚非确定根因。PWM平均电压不等于实际端电压，电流已滤波，R/L/换向磁通都有不确定性，电气估计不能代替独立转速计。

MPS官方离轴应用说明（https://media.monolithicpower.com/document/appnote_Using_MagAlpha_in_off-axis_mounting_rev1.1_SR.pdf）说明磁铁/芯片偏轴可能使两个场分量幅值不同，导致椭圆误差和非线性角度。这是磁编码器通用机制参考，不是本项目MT6701已经损坏或安装必错的证据，也不能套用MPS器件参数。

下一必要检查是实际磁铁/芯片位置、磁化方向及独立角度/转速参照。没有据此添加角度修正表、隐藏波形或采用外环参数；本轮无新运动。

## 参数敏感性复核

对既有保存的R=1/2/4/6Ω、L=0/.02H组合复核：9%PWM下电气二阶幅度COM4最高约5.2%、COM23最高约9.5%，仍低于角差速度17–27%；但6%PWM下COM23电气估计可达30–33%，与角差速度范围重叠。因此“只有2–4%”仅适用于先前指定模型与高档工况，不能泛化到所有参数/速度。

该敏感性进一步说明需要物理安装信息及独立基准，不足以定论编码器损坏。实时状态复核两板均idle/PWM0、速度0、nFAULT1，约19.65/19.70V；本轮未启动运动。等待用户提供磁铁/芯片正面与侧面相对位置照片；照片用于定位安装，不等于角度精度验收。
