# 新电流候选下的旧速度环检查

原始记录 `evidence/moving-mechanics-1788882997020.json`。

通过新批次±100/150/200mA验证的模型与PI整组应用到两板，隔离旧角度补偿，速度环保留旧KP=.0008/KI=.016，电流输出上限.3A。各板8条600ms、±10/20输出度每秒测试均完成，无中止。试后电气组、速度组、旧补偿恢复，cleanup.ok=true，两板idle/PWM0。

COM4全样本速度跟踪RMS误差11.98度/秒，峰值60.88度/秒；COM23 RMS11.30度/秒，峰值41.58度/秒。末200ms均速仍有接近0或显著超过目标的阶段，不通过速度跟踪验收。

这不是新电流候选全范围失败的证明，也不是它解决低速的证明。旧速度环的起动和跟踪不可靠，不能把其受限响应直接当作充分激励的机械模型数据。下一步直接电流激励采加减速响应，避免用尚未调好的外环辨识外环所需的模型。

采集工具新增 --validated-current，仅接受保存的新批次六脉冲通过且恢复成功的候选；新增电气组恢复读回、零点门槛、profile/sync检查与失败退出码。不改变1.5A/5.2保存设置，不采用未验收外环。
