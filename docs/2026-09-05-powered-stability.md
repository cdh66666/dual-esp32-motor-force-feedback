## 3. 0.5.2 已修改并烧录

1. **发送满队列重试**：0.5.1 在 TinyUSB FIFO 空间为零时直接返回，缺少重新触发发送的步骤；现在每次调度最多进行一次有界写入/flush，包括满 FIFO 或零写入的情况，仍限制到每 1 ms 一次，不忙等。
2. **跨重启诊断**：恢复记录改为 `RTC_NOINIT_ATTR`，加 magic / 计数反码校验、上电初始化和前次 USB 阻塞标记。两次上限不再依赖普通 `.rtc.data` 初始化值；增加 `USB_RECOVERY` 回读。真实跨故障软重启验证仍待做，当前已通过逻辑模拟。
3. **后台失效句柄清理**：异常结束的读线程关闭自己拥有的失效句柄、取消旧命令代次，不再持续假报已连接；后续正常连接不自动唤醒或恢复旧目标。源码已通过 17 项后端单元测试，部署状态需以后台重启后的实测为准。
4. **测试捕获完整性**：测试命令异常后仍尽力发送 STOP 和 SLEEP，并独立记录故障后窗口；预检身份失败时不会向错误板卡发送清理命令。

固件版本 `0.5.2-link-stability` 已在电机断电后烧录并回读，NVS 标定未擦除。SHA256：`edd62bb02b289fd4322aa3ce028d8edfea04379cd63b6d7b6b16f6775b26e2b0`。上传记录：`evidence/flashing/20260905-052-link-retry-upload.log`。

10 组离线回归通过，含满 FIFO 有界重试、跨软重启计数逻辑、失效 Windows 句柄关闭、原三环和旋钮数学、网页坐标/续租/STOP 契约；结果：`evidence/link-stability-offline/0.5.2-link-stability/checks.json`。**这些修改不能替代新版本带电复测。**
