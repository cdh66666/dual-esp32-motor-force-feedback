# 输出轴坐标与电流力反馈旋钮：离线交接

日期：2026-09-05。源码版本：`0.5.0-output-haptic`。

初始开发阶段按用户要求仅修改代码、编译并运行隔离测试。随后用户明确要求“烧录”，已于 2026-09-05 烧录并回读确认 `0.5.0-output-haptic`，后端也已重启。烧录前实测母线约 19.5 V，先执行 STOP/SLEEP 并确认 PWM=0；本次没有启动电机或旋钮。先前运动基线是 `0.4.25-commissioned-36gp`，不能把本次版本/通信验证等同于新旋钮手感验收。

## 1. 全页统一输出轴

36GP-555 的档案减速比为 **5.2:1**，磁铁位于电机后轴。角度、速度、目标、曲线、图上最新值和 CSV 均按输出轴表示，°/圈选项统一转换数值。暂未获取有效档案减速比的帧不进入图表，防止混用两种坐标。

| 对象 | 换算/行为 |
|---|---|
| 位置、速度、位置目标、内环速度参考 | 电机轴值 ÷ 减速比后显示 |
| 输出轴单圈角度 | 从输出轴多圈角度取模，不是后轴单圈值直接除比 |
| 旧固件位置/速度命令 | 输出轴目标 × 减速比后传输 |
| 新固件 `posout` 命令 | 直接接收输出轴角度；范围 ±36000°，即输出轴 ±100 圈 |
| 速度 Kp/Ki | 页面输出轴基准 = 原电机轴基准 × 减速比，下发除回 |
| 位置 Kp/Ki/Kd | 不变：位置误差与输出速度同时缩放，比例抵消 |
| 速度限幅、角度死区 | 页面值 ÷ 比 / 写回 × 比；原加速度内部值不变 |
| 电流 PI、电流限幅、辨识 R/Ke | 不因显示坐标变化而修改 |

已用隔离测试核对：后轴 1872° → 输出轴 360° → 页面 1.000000 圈；输出轴目标 1 圈在旧协议下发送后轴 1872°。CSV 列名含 `output_` 和 `gear_ratio`，不把后轴数据冒充输出轴独立实测精度。减速箱齿隙、弹性和效率仍须实测，不能由后轴传感器凭空消除。

## 2. 四种手感

采用独立原创的连续力曲线，不移植无刷 FOC 的换相部分。有刷 H 桥继续由已经调过的电流 PI 驱动。

1. **连续卡点**：默认 15°，每个输出轴整圈有 24 个稳定力孔；间距滑块 2–90°。
2. **弹性回中**：以启用位置为中心，偏转越大恢复电流越强，平滑饱和；“间距”在此代表柔度。
3. **纯阻尼**：电流方向始终与转速相反，不把角度拉回原位；静止时理论目标为零。
4. **有边界的卡点**：两端为连续软弹簧；有效边界向内对齐整数卡点并在页面显示，绝不是机械止挡。

令 `x` 为输出轴相对启用中心的角度（°），`w` 为输出轴速度（°/s），`s` 为卡点间距，`A` 为电流峰值：

```
普通卡点：I = -A * sin(2*pi*x/s) - D*w
弹性回中：I = -A * tanh(x/s)    - D*w
纯阻尼：  I =                  - D*w
```

静态卡点力在中心和卡点分界处连续，避免切换索引时的矩形电流跳跃；指数/正弦属于虚拟手感，不是转矩标定。强度用绕组 mA，未给出未实测的 N·m。

默认峰值 200 mA、阻尼 1 mA/(输出轴 °/s)，总和限幅 ±600 mA。启用和改配置时用 80 ms 包络建立手感；平时直接送 500 Hz 电流参考，不用额外的每次换向慢爬坡，避免相位滞后。仅使用 36GP-555 已调电流环档案，不套用旧 775 的强制 2 A 下限、速度 PI 或摩擦补偿表。

## 3. 时序、交互与安全

- 力感计算 500 Hz → 电流 PI 2 kHz → H 桥；网页只有 100 Hz 遥测与约 4 Hz 租约，不承载力控实时闭环。
- 普通位置/速度/电流滑块按最新值最多 40 Hz 发送，连续拖动不会一直推迟到松手；ACK 未返回时合并过时目标。当前已调电流/速度参数与连续变速算法不变。
- STOP 会取消未发送目标和服务器中已排队的旧命令。旋钮启动/续租回执与会话 token 匹配；迟到续租不能重新起力。
- 每次明确启动才捕获中心；参数预览、刷新、重连、清零、恢复不自动启用。清零先 STOP，不能在力场运行时悄悄移动原点。
- 板端有 1 s 不可复活租约、60 s 硬会话上限；页面隐藏/关闭尽力 STOP，并停止续租。浏览器卡住也不需要依靠它来执行到期停力。
- 始终保留原 VM、nFAULT、PWM 初始化、编码器陈旧、看门狗保护。旋钮超过输出轴 720°/s、无效传感数据、采样电流超过 1.2 A 会停；软限位不能作为人身防护。
- 页面初次连接先查询能力；未烧录新固件时“启用旋钮”禁用。旧固件仍可用输出轴换算后的三环调试；旧固件位置量程保持它可接受的真实范围。

### 协议新增（调试串口）

```
CAPS output_position=1 knob=1 haptic_protocol=1    # model 查询附带回报
posout OUTPUT_DEGREES MAX_DUTY TIMEOUT_MS
knob config EFFECT SPACING_OUT_DEG PEAK_MA DAMPING_MA_PER_OUT_DPS RANGE_OUT_DEG
knob start TOKEN       # 必须已 STOP/WAKE、编码器近静止、驱动与电源有效
knob keep TOKEN        # 不能启动或复活过期会话
knob stop
knob status
```

`EFFECT`=0/1/2/3；TOKEN=1..1000000000；配置既不启动也不续租。S 帧协议保持原电机轴字段以兼容既有采集工具；模式 5 的位置目标字段表示当前力孔中心的后轴等效角度，网页收到后统一除减速比。

## 4. 验证与限制

已完成：

- PlatformIO `esp32-s3-devkitc-1` 编译与后续用户授权 upload；USB 应用口 COM23 → 同一 MAC 的下载口 COM18 → 应用口 COM23。上传校验成功，板端回读版本 `0.5.0-output-haptic`，`CAPS output_position=1 knob=1 haptic_protocol=1`。
- 原控制数学回归、2 kHz/500 Hz/200 Hz 调度辅助函数回归。
- 旋钮数学：四种力感、正负方向、卡点/边界连续性、阻尼功率符号、限流、非有限输入、时钟回绕、旧租约不能起力、60 s 上限。
- 假设机械模型的完整过程仿真：三种示例惯量、3 ms 假设电流滞后、15 s 轨迹并检查最后 10 s；这些模型不是本电机已辨识出的参数，也不能证明实际手感稳定。
- 后端 13 项自动测试和串口会话生命周期测试，串口为假对象；包含 STOP 队列取消、重连前指令不能跨到新会话、回执完整 token 匹配。
- 3 个浏览器隔离测试：静态文件直接从源码提供，全部 HTTP/API 请求拦截，不访问真实串口服务；测试换算、CSV、能力门禁、断电拒绝、启动/停止、续租、切换到速度控制、连续拖动与 STOP 取消。

可运行 `python tools/check_haptic_offline.py` 复核；结果及固件 SHA256 位于 `evidence/haptic-offline/checks.json`。`ui.png` 是明确标注的离线界面测试图，不是新电机运行证据。

## 5. 实机验收进度与后续步骤

1. 已完成身份核对、烧录、新后端重启和版本/能力查询。固件 SHA256 为 `8609b3f34d5fda8ccb70f21c3fef1004b96040906c58e622f87cb37d13345848`；日志见 `evidence/flashing/20260905-1217-upload-output-haptic.log`。首次上传被网页自动连接下载口抢占，暂停后台后完成；未清除 NVS 标定。烧录后查询 `knob status` 为 active=0，diag 为 nsleep=0/nreset=0/PWM=0，19.86 s 空闲窗口遥测为 100 Hz。
2. 接电后先读母线、nFAULT、编码器、零电流，再做短时低电流正反方向验证。桌面示例电源和磁铁安装位置改变后不能跳过检查。
3. 保留原三环基线，采集小电流阶跃、输出轴 0.05/0.1/0.5/1 rps 连续变速、小角度往返及到位后至少 10 s 的全程数据。比较响应时间、过冲、纹波、停滞与误差；不只看最终一帧。
4. 先试 15° / 200 mA 卡点和小阻尼，确认电流符号与手感方向；再逐步缩小间距、增大强度（≤600 mA），记录峰值电流、振荡与温升，测试失联/STOP。不要把减速箱无法反驱或齿隙当成 PID 能完全解决的误差。
5. 只有实测更快且不增加振荡/温升的参数才替换现有基线。“最好效果”尚不能由离线模型保证；当前已优化的是控制路径和交互延迟，而不是宣称达到无刷直驱的全部机械手感。

用户随后报告大电流测试停机，已定位旧日志中的 `encoder_stale` 触发点，见 [诊断记录](2026-09-05-current-stop-diagnosis.md)。采样迟到的具体原因尚未区分调度/I2C 瞬态错误，未更改保护阈值或再次执行大电流试验。
