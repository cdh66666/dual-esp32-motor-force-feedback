# 固定 PWM 正反转编码器连续测试

用户确认两台均无手柄、无外部负载。2026-09-08 实机运行：两板分别按 123、246、369 / 4095 固定 PWM，正反各 20 秒，共 12 段、240 秒。100 Hz 保存原始角度计数、多圈位置、电流、速度、母线及状态。

## 测量结果

以下圈数为输出轴圈数（电机角度除以 5.2），不是独立外部测量。

| PWM | COM4 正转 / 反转 | COM23 正转 / 反转 |
|---|---:|---:|
| 约 3% | +0.0032 / -0.0035 圈 | +0.0017 / -0.0025 圈 |
| 约 6% | +17.890 / -18.653 圈 | +16.872 / -18.245 圈 |
| 约 9% | +31.699 / -31.716 圈 | +30.724 / -31.157 圈 |

- 12 段均完成，未触发脚本中止或报告控制器故障。
- 各段有效样本 1997–2000 条；板端样本最大间隔 10 ms。
- 原始计数独立展开与固件多圈增量比较，最大偏差 0.320 电机度，约 0.062 输出轴度；没有整圈跳变。该小偏差的来源尚未确定。
- 没有超过 1 电机度的反向原始计数步进。
- 约 6% / 9% 各旋转段累计约 88–165 个电机圈；约 3% 两板均未持续转动，不能用该档验证连续多圈。
- 板端反馈电流最大绝对值 0.628 A；这不是电源输入电流或 PWM 开关周期瞬时尖峰测量。
- 最终两板均 STOP ACK，control=idle、PWM=0、velocity=0、nFAULT=1。

## 结论与边界

本轮没有发现编码器读取中断、反向跳读或跨圈展开错误，不能把此前低速异常直接归因于编码器损坏。最低档未持续旋转提示起动阻力/低速驱动区间值得优先排查。

恒定 PWM 下的速度仍有波动；本试验不能区分真实机械速度波动与周期性角度测量误差，也不能认证绝对角度精度。原始计数与多圈位置来自同一传感器，不能互相充当独立角度基准。三环整定与受力稳定性仍未验收。
