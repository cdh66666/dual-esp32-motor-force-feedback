# 2026-09-05：电流/速度抖动改进候选与 25 mm 旋钮力臂

对象：36GP-555，5.2:1，后轴 MT6701；USB 身份 `68EE8F52A79C`，当前 COM23。新控制源码 **0.5.5-control-timing 已编译，尚未烧录**。板上最后回读版本仍为 0.5.4。本文不声称已经改善真实电机或手感。

## 确定的代码缺陷与本次改动

1. 调度器仅在延迟超过四个周期时跳过旧任务；较短延迟会连续补算过期的电流/速度任务。现在每次只计算一次，把下一截止时刻推进到未来，正常情况下保持周期相位。100 Hz 遥测也使用同一规则，不补发过期时隙来伪装采样率。
2. 电流滤波原来每调用一次乘固定系数，且 PWM 瞬时过零会改变系数。现在按实际间隔计算指数滤波系数，工作态时间常数约 1.522 ms，对应原 500 µs 下的 0.28；工作态不随 PWM 过零切换滤波速度。rawadc 诊断不再推进正在使用的控制滤波器。
3. 电流积分和 RAM trace 时间戳改用 ADC 采样完成时刻，而非本轮循环开始、I2C 读取之前的时刻。增加最短/最长实际采样间隔诊断。目标 2 kHz 不等于已证明实时 2 kHz。
4. 36GP 速度改为对最近 4 ms 的已接受位移估计斜率，然后保留 2 ms 速度滤波。多圈位置不做这层滤波、不丢计数，原始单次差分速度仍在遥测最后一列。额外延迟需要通电重新验收，不声称只降噪而完全无代价。
5. 没有修改本板保存的 PI/PID、R/Ke、方向、采样极性、5.2 换算或电机电流包络；没有移除 nFAULT、VM、编码器时效、任务看门狗和旋钮租约保护。

## 25 mm 杆与力反馈

- 网页新增“轴心到施力点”的力臂滑块，默认 25 mm；仅改变显示换算，不发送动作。
- 旋钮网页默认绕组峰值从 200 mA 改为 **500 mA**，仍需显式启用，下发配置后才生效；旋钮限幅仍为 600 mA。固件未收到配置时的默认值不被伪装成网页已应用值。
- 显示目标电流和实测电流，避免只看目标就误认力矩已经输出。
- 使用本板回读 Ke 作 SI 理想模型：Kt≈Ke=0.022754 N·m/A；0.5 A、减速比 5.2 时，理想输出转矩约 0.05916 N·m。作用于距轴心 25 mm 处，理想切向力约 **2.37 N**。这是不计齿轮箱损耗的模型值，不是实测手力或成年人的最大手力；齿隙、摩擦、电流跟踪、安装误差均会影响效果。
- 重连、MCU 重启及已知电机档案变化后清除旧 Ke 估算。未取得本板模型时显示“暂不能估算”，不使用另一电机的数值。
- 保留短通信租约和手动再次启用。通信失效时不能靠加大电流解决无输出，也不能自动续发旧力矩。
