# 工作限流与五秒故障确认

本轮按用户明确要求更新力反馈/直接电流 interaction guard：保持工作目标为配置最大电流的 80%（现有配置 1.50 A，目标不超过 1.20 A）。实测达到配置上限时立即命令 PWM=0、保持会话及遥测；降至工作目标上限内后，用 100 ms 恢复控制权限。不在过流期间强制持续驱动。

实测连续达到/超过配置上限 5000 ms 才返回锁定过流故障，任何低于该上限的采样清零确认计时。绝对值达到 5 A 仍立即保护，这是保留的紧急边界，不是允许输出 5 A。供电、无效反馈、驱动故障等保护未移除。旋钮独立保护未改；本次针对双板力反馈和直接电流的 interaction 路径。
