# 0.5.9 同步记录候选

- 在电流控制周期 RAM 记录中增加电机轴位置、速度、编码器数据年龄和母线电压；停机后逐行导出，不在控制周期打印。
- 64 位板端时间替代会在约 71 分钟回绕的 micros 时间，保持与网页遥测时基一致。编码器是周期内最近一次读数，不宣称 ADC 与编码器硬件同时采样。
- 新记录电气拟合直接使用随记录保存的速度和母线；编码器年龄超过 3 ms 时拒绝该窗口，不回退到网页插值。
- 机械拟合从板端记录按至少 10 ms 间隔取样。辨识增加至八个短脉冲，单次幅度与时长不增加，最后留出较长的 -150 mA 脉冲。没有放宽误差或运动保护。
- 前端仍可离线分析旧记录；新自动采集要求 0.5.9，避免误用旧固件。
- 编译通过：RAM 86252 bytes，Flash 448653 bytes；离线拟合、真实数据拒绝、取消恢复及力反馈状态测试通过。尚未烧录，不能声称同步采样实机通过或三环整定完成。
